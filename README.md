# Personal website

Static personal website (HTML/CSS/JS) with project pages and assets.

## Local preview

From the repo root:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages (optional)

- **User site**: create a repo named `<your-username>.github.io` and push this content to the `main` branch.
- **Project site**: create any repo name and enable Pages in GitHub: **Settings → Pages → Build and deployment → Deploy from a branch** (`main` / `/root`).

## Reuse / License

Feel free to reuse the website structure and code as a template for your own personal site.

- **Allowed**: HTML/CSS/JS structure, layout, components, and general page organization.
- **Not included by default**: my personal content (text), PDFs, and especially **images**. Please replace these with your own assets.
- **Images**: do **not** reuse the pictures in this repo without asking for permission.
